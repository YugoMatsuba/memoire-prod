# Development Tools

This document lists the main development tools used by the frontend and backend applications.

## Frontend

- Language: TypeScript
- UI library: React
- Build and development server: Vite
- Static type checking: TypeScript compiler (`tsc`)
- Formatting: Prettier
- Linting: ESLint
- Package management: npm
- Unit testing: Vitest
- Component testing: React Testing Library

## Backend

- Language: Python 3
- Runtime data validation: Pydantic
- ORM: SQLAlchemy
- Database migrations: Alembic
- Static type checking: Pyright
- Formatting: Ruff
- Linting: Ruff
- Package management: uv
