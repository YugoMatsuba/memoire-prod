# Git Standards

This document describes the Git standards used for mémoire development.

## Branches

- Each ticket implementation should be developed in a separate branch.
- Branch names should use the format `feature/<short-description>`.
- The short description should be a single word or use underscores when multiple words are needed.

## Commits

- When a commit is pushed to the remote repository, the commit message should include the GitHub issue number and title.
- Example: `issue-11 Implement memory details view`
